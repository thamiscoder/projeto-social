# Projeto social

Projeto de página web estática desenvolvido como estudo do curso **HTML5 e CSS3 do Curso em Vídeo**, no **Módulo 04, Capítulo 23 - Projeto Redes Sociais**.

O objetivo do projeto é simular uma interface de smartphone com atalhos para redes sociais. Ao clicar nos ícones laterais, a tela exibida dentro do celular muda, criando uma navegação visual usando **iframes**, imagens e páginas HTML separadas.

## Sobre o projeto

O `projeto-social` é um exercício prático voltado para treinar a criação de páginas estáticas com HTML5 e CSS3, usando posicionamento, imagens, links e incorporação de conteúdo por iframe.

A página principal exibe um celular centralizado na tela e botões de redes sociais ao lado. Cada botão abre uma página específica dentro da tela do aparelho.

## Funcionalidades estudadas

- Estruturação de páginas com HTML5;
- Estilização com CSS3;
- Uso de `iframe` para carregar páginas internas;
- Links com destino para o iframe;
- Posicionamento de elementos na tela;
- Uso de imagens como plano de fundo;
- Simulação visual de um smartphone;
- Botões circulares para redes sociais;
- Efeitos de `hover` nos ícones;
- Organização de arquivos em pastas de estilos e imagens.

## Tecnologias utilizadas

- HTML5;
- CSS3.

## Como visualizar o projeto

1. Baixe ou clone este repositório:

```bash
git clone https://github.com/thamiscoder/projeto-social.git
```

2. Acesse a pasta do projeto:

```bash
cd projeto-social
```

3. Abra o arquivo `index.html` no navegador.

Também é possível hospedar o projeto em serviços como GitHub Pages, Netlify ou Vercel, já que ele é composto apenas por arquivos estáticos.

## Objetivo de aprendizado

Este projeto foi feito para praticar conceitos apresentados no Curso em Vídeo, principalmente:

- navegação com iframe;
- criação de páginas internas;
- composição visual com imagens;
- interação simples com links;
- organização básica de um projeto HTML e CSS.
